# BillingRefactoring (NetBeans / Maven project)

Assignment 02 - Refactoring legacy `OrderBillingEngine` with JUnit 5, code-smell audit and SOLID design.

* Open in NetBeans: **File -> Open Project** and select this folder (it is a standard Maven project, JDK 17+).
* Run tests: right-click project -> **Test** (Alt+F6) or `mvn test`.
* Run demo: right-click project -> **Run** (`com.uet.billing.Demo`).
* Documentation per task: see [`tasks/`](tasks/README.md).
