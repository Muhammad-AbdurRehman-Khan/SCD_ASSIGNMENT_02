# Assignment 02 - Task Folders

Each task of the assignment has its own folder so that the marker (and you) can find the evidence quickly.

| Folder | Assignment task | What is inside |
|--------|-----------------|----------------|
| [`task1_safety_tests/`](task1_safety_tests/) | Task 1 - JUnit 5 safety net | Overview of every test class (the tests themselves live in `src/test/java`, the Maven/NetBeans standard location) |
| [`task2_audit/`](task2_audit/) | Task 2 - Code smells & SOLID audit | `CODE_SMELLS_AND_SOLID_AUDIT.md` with line numbers, reasons and fixes |
| [`task3_refactoring/`](task3_refactoring/) | Task 3 - Clean refactored code | Architecture diagram and before/after metrics (the code lives in `src/main/java`) |
| [`task4_git_history/`](task4_git_history/) | Task 4 - Git commit trail | The 10 planned commits and the `git log --oneline` output for the report |

> Java source code stays in `src/main/java` and `src/test/java` because Maven and NetBeans require
> that layout. The `tasks/` folder holds the documentation and evidence for each task.
